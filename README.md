**Distributed Systems Experimentation Platform | Final-Year Project · In Development**

Building a web application to design distributed architectures, run them locally and study resilience through controlled failure experiments.

- 🏗️ **Backend:** Modular **Spring Boot** application with **PostgreSQL**, **Flyway** and ownership checks
- ⚛️ **Frontend:** **React** and **TypeScript**, with authentication, a component catalogue, private projects and scenario management
- 🧪 **Quality:** Automated unit, integration, API and browser tests, with **GitHub Actions** and **SonarQube Cloud**
- 🔭 **Next steps:** Visual topology editing, Docker execution and failure experiments

`Java` `Spring Boot` `PostgreSQL` `React` `TypeScript` `Docker` `GitHub Actions`

`Python` `Semantic Kernel` `Azure OpenAI` `React` `Docker Compose`
